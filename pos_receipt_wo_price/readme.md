# Point of Sale - Receipt Without Price

This module adds a new configuration for Point of Sales (PoS).

In the configuration of a PoS, you can now check the box "Allow receipts without price" and you will be able to print
receipts without price as mentionned.

This kind of receipt is mostly used when a customer buys a gift, with this feature the customer can ask for the receipt
without price and give it with the gift so the person who received the gift can make an exchange in the shop.

On the payment screen you can toggle the receipt without price. This way, the receipt without price will be printed 
right before the receipt with the price.

In case you do not have a printer configured to automatically print receipt after payment, you have a button to print it
in any case.

It is also possible to reprint a receipt without price in the order panel.
